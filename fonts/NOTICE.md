## Design names and original mode

The fourteen reference-inspired designs reuse these five OFL font families with different vector stroke details. They are not fourteen separately extracted or newly authored font files. The fifteenth design, “原款花字” (`legacy`), retains the user's system Song font and original ornament rendering. No proprietary system font file is copied into this distribution.
